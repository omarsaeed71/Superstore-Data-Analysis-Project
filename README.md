# Superstore Data Analysis Project

## Project Overview
This project focuses on analyzing Superstore sales data to understand business performance and generate meaningful insights.

## Project Objectives
- Analyze Superstore sales data.
- Transform raw transactional data into a reliable analytical model.
- Build a Data Warehouse using SQL Server.
- Perform ETL processes using SSIS.
- Apply Dimensional Modeling and Star Schema.
- Create interactive Power BI dashboards and KPIs.

## Tools & Technologies
- SQL Server
- SSIS
- Power BI
- DAX
- Star Schema
- Data Warehouse
